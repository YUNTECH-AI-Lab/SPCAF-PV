# SPCAF-PV
 A Synthetic Physics-based Cloud-Aware Framework for Residential PV Fleet Generation Dataset
## Running from the Command Window (Windows)

1. Press the **Windows key**, type `cmd`, and press **Enter** to open Command Prompt.

2. Navigate to the folder where you placed the project, for example:
   ```bash
   cd Desktop\SPCAF-PV
   ```

3. Check that Python is installed:
   ```bash
   python --version
   ```
   If this shows an error instead of a version number, install Python from [python.org](https://www.python.org/downloads/) first, making sure to check **"Add Python to PATH"** during setup.

4. Install the project's dependencies:
   ```bash
   pip install -e .
   ```
   This may take a minute or two the first time.

5. Start the web app:
   ```bash
   synpv app
   ```
